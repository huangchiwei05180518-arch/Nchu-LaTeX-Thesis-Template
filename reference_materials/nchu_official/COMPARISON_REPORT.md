# NCHU 官方要求與本模板比對

比對日期：2026-07-18

比對基準：

1. 教務處 F2-65 學位論文格式規範（111.4.21 修訂）。
2. 圖書館論文上傳手冊（2026.02 v2）。
3. 圖書館論文上傳自我檢核表（2026.06 v2）。
4. 電機系論文考試申請注意事項（2026-05-04 更新）。
5. 電子學位論文系統提供的中英文 Word 範本。
6. 圖書館提供的中英文 Overleaf/LaTeX 範本（2025.04，本地 ZIP）。

## 2026-07-18 實作更新

使用者下載的兩份官方 Overleaf ZIP 已完成原始碼比對。官方範本的關鍵設定為 `oneside, openany, a4paper`、四邊 3 cm、楷體／Times New Roman、1.5 倍行距、審定書置於書名頁後，以及表目次在圖目次之前。

本模板已完成原報告列出的 P0 項目：

1. `submission=electronic|print`：電子版移除紙本空白頁；紙本版保留外封面、空白頁與書名頁。
2. 中文日期改為中式數字，例如「中華民國一百一十五年八月」。
3. `profile=general|ee`：電機系 profile 使用楷體 13pt、Times New Roman 12pt。
4. 電子版改用 `openany` 與 `\clearpage`，避免 `\cleardoublepage` 產生非必要空白頁。
5. `scripts/preflight_pdf.ps1` 檢查 A4、20 MB、加密、可搜尋文字與字型嵌入。
6. 審定書與授權書缺檔會警告，且只在對應模式加入。
7. 已加入 placeholder、中文題目 60 字警告、英文姓名說明、圖表資料來源命令與電機系上傳檔名建置選項。

本機完整建置結果：電子版 14 頁、紙本版 16 頁，兩者均通過 PDF preflight；另以 DFKai-SB 13pt 完成電機系 profile smoke compile。最終個人論文仍須補入簽妥審定書、授權書（如適用），並人工核對題目、姓名、簽章及上傳系統欄位。

狀態定義：

- 符合：目前模板已有明確實作。
- 部分符合：可手動做到，但模板沒有模式、檢查或完整預設。
- 缺口：目前輸出會違反要求，或缺少必要產物。
- 系所 profile：只適用特定系所，不應作為全校唯一預設。

## 結論

模板目前已涵蓋 A4、3 cm 邊界、封面、頁碼、圖表、電子／紙本模式、中式日期、電機系字型 profile 與 PDF preflight，可作為送審版與紙本版的共同來源。

仍未自動化的主要項目為書脊產生、中西文參考文獻分組，以及必須人工完成的簽章與外部系統欄位一致性核對。

## 原建議實作順序

### P0 - 影響是否能通過圖書館審核（本次已完成）

1. 新增 `submission=electronic|print`：
   - electronic：書名頁、審核頁、誌謝、摘要、目次、表目次、圖目次、正文、參考文獻、附錄。
   - print：封面、空白頁、書名頁、審核頁、NCHU 授權書影本、其餘內文。
2. 修正民國年月為中式數字。
3. 新增 `profile=general|ee`，其中 EE profile 使用中文楷體 13 點、英文 TNR 12 點。
4. electronic 模式改用 `openany`/`\clearpage`，消除不必要空白頁。
5. 新增 PDF preflight：A4、頁數、大小、可搜尋、字型內嵌、未加密、無使用者浮水印。

### P1 - 降低人工錯誤

1. 檢查 title、author、advisor、institute 等欄位是否仍為 placeholder。
2. 對超過 60 字或可能超過三行的中文題目發出警告。
3. 審核頁檔案不存在時發出警告。
4. 加入英文姓名格式與關鍵詞填寫規則。
5. 新增 release checklist 與 EE 檔名產生指令。

### P2 - 完整紙本支援

1. 依 F2-65 附錄四新增書脊產生器。
2. 提供圖表資料來源命令。
3. 提供中西文參考文獻分組範例。
4. 加入封面、前置頁、正文與書脊的 PDF 視覺回歸測試。
