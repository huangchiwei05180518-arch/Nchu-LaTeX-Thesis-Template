## 電機系目前加嚴要求

電機系官方網站連到的 2026-05-04 注意事項明定：

- 中文：標楷體 13 點。
- 英文：Times New Roman 12 點。
- 上傳版 PDF 的檔名格式為「學號-碩士論文」。
- 紙本平裝本 2 本，封面顏色不限定。
- 口試前與定稿後皆須完成 Turnitin 原創性比對。

這些是電機系、通訊所、光電所適用的系所要求，不應硬編碼成全校所有系所的唯一預設；模板宜以 profile 選項支援。
