這個版本支援雲端同步，但需要你自己提供 Supabase 專案資訊。
第一次使用流程：先在 Supabase 建專案並執行附上的 SQL，接著把 URL、anon key、同步識別碼貼進來，再按「用目前進度初始化雲端」。
之後在另一台裝置，只要輸入同一組 Supabase URL、anon key、同步識別碼，再按「從雲端讀取」，就會看到同一份資料。
